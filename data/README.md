# Data files

This folder contains the reference data files used by CassavaGenDup.

## Files

- `genotypedb.csv`: curated genotype database used for duplicate detection and varietal identification.
- `passportdb.csv`: curated passport database associated with the genotype database.
- `SNPY.csv`: SNP marker information used by the pipeline.

The initial release includes a curated reference database of 12,000 cassava samples.

Users can replace or update these files if they want to run CassavaGenDup with their own curated databases.
