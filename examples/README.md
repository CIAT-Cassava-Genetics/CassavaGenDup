# Example files

This folder contains example input files for testing selected sections of the CassavaGenDup pipeline.

## Files

- examplegenodata.csv: example genotype dataset containing four samples and 96 SNP markers, used to test the **Reading Data** section.
- samples.csv: example list of sample identifiers used to test the **Plot Heatmap of Samples** and **VCF Report** sections.

## How to use

### Genotype input example

Copy examplegenodata.csv into the `input/` folder.

In the **Reading Data** section of `CassavaGenDup.ipynb`, use the following parameters:

```python
final_call = "Final"
assay_name = "Assay"
sample_name = "Name"
skiprows = 0
```

The example file has column names in the first row. For standard Fluidigm chip files, use the default `skiprows = 15`.

### Sample list example

Copy samples.csv into the `data/` folder.

In the **Plot Heatmap of Samples** or **VCF Report** section, use:

```python
sample_list_file = "samples.csv"
```

The file contains one sample ID per row, without a header. Sample IDs must match those generated by the pipeline or present in the genotype database.

## Note

These files are provided for testing and demonstration purposes. Users can replace them with their own genotype files and sample lists following the same formats.
